Retail Sales Data Analysis Using MySQL

Project Overview

This project analyses retail sales transaction data using MySQL to uncover business insights, evaluate sales performance, measure profitability, and investigate product returns.

The objective is to transform raw retail transaction data into meaningful information that supports business decision-making.

Business Objectives

* Analyse overall retail sales performance.
* Identify top-performing products and product categories.
* Evaluate gross profit and profit margins.
* Investigate product return patterns.
* Measure monthly revenue and growth.
* Analyse supplier performance.
* Evaluate sales channel performance.

Technologies Used

* MySQL
* MySQL Workbench
* SQL

SQL Skills Demonstrated

* SELECT statements
* WHERE filtering
* GROUP BY and ORDER BY
* Aggregate functions (SUM, COUNT, ROUND)
* CASE statements
* Common Table Expressions (CTEs)
* Window functions
* RANK()
* LAG()
* Revenue contribution analysis
* Monthly sales analysis
* Return rate calculations
